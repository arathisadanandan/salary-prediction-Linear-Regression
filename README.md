
# Salary Prediction Using Linear Regression

## Project Overview

This project uses Machine Learning to predict an employee's salary based on years of work experience using a Linear Regression model.

## Objectives

* Understand the relationship between years of experience and salary.
* Perform basic data exploration.
* Train a Linear Regression model.
* Evaluate model performance using regression metrics.
* Visualize actual salaries and the regression line.
* Predict salary for new experience values.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## Machine Learning Algorithm

**Linear Regression**

Linear Regression estimates the relationship between an independent variable and a continuous target variable.

* Input feature: Years of Experience
* Target variable: Salary

## Project Workflow

1. Import the required libraries.
2. Load and explore the dataset.
3. Check for missing values.
4. Separate features and target.
5. Split data into training and testing sets.
6. Train the Linear Regression model.
7. Predict salaries.
8. Evaluate model performance.
9. Visualize the regression line.
10. Predict salary for new experience values.

## Evaluation Metrics

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* R-squared Score (R²)
